- 现象：health 的 `coverage` 一直缺 `limit` 字段，折腾很久（曾误判是变量名冲突、端口隧道）。
- 根因：`q = (sql)=>db.prepare(sql).get()['count(*)']`；限额查询原写 `SELECT count(DISTINCT code) FROM ...`（**无列别名**），SQLite 返回列名是 `count(DISTINCT code)` 而非 `count(*)` → `['count(*)']` 取到 `undefined` → 被 `JSON.stringify` 静默丢弃。
- 修复：改成 `SELECT count(*) FROM (SELECT DISTINCT code FROM daily_nav WHERE limit_amount IS NOT NULL)`，列名即 `count(*)`。直查验证 health coverage 现含 `limit: 282`。
