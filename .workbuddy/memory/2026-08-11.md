## 调研结论（免费基金数据接口）
- **Eastmoney JSON 端点（已在用）本质上是 API 级**：`lsjz`(净值历史)、`fundgz`(估值)、`FundArchivesDatas(jjcc/zcpz/hytz/qscc)`(持仓/资产/行业/区域)、`jdzf`(业绩) 全返回结构化 JSON，稳定、免费、无 token。覆盖约 90% 字段。
- **真正脆弱的只有两处**：① 概况页 `jbgk`（GBK HTML，取规模/费率/经理/公司/成立日）；② 季报 PDF（行业/区域兜底）。
- **Tushare**（tushare.pro）：真·REST API（HTTP POST `api.tushare.pro`，**可用 Node 直接调，不必装 Python**），免费但需 token + 积分：`fund_basic`(经理/公司/成立日,2000分)、`fund_nav`(净值,2000分)、`fund_portfolio`(持仓季度,**5000分**)。QDII 覆盖部分（老牌有，小众可能缺）。
- **AkShare**（akshare.akfamily.xyz）：Python 库，免费、**无 token 无积分**，封装东财，QDII 覆盖好（`fund_portfolio_hold_em`/`industry_allocation`/`basic_info_xq`/`value_estimation`/`rating_all`）；但本质是爬虫打包，东财改版会断，且要 Python 运行时。

## 推荐架构（待用户确认概况字段来源）
1. 主源 = Eastmoney JSON（Node 直接 HTTP，无依赖）。
2. **删掉季报 PDF 兜底层**：`FundArchivesDatas hytz/qscc` 已给行业/区域；缺失留空（前端已 guard）。
3. 概况字段（规模/费率/经理/公司/成立日）那唯一 HTML 处 → 候选：Tushare `fund_basic`(A,推荐) / AkShare(B,要Python) / 保留 jbgk HTML(C,最省事)。
4. 风险指标本地从 NAV 历史计算（波动率/最大回撤/夏普），不依赖接口。
